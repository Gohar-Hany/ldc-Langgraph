# LDC LangGraph

A repository dedicated to learning, practicing, and building **LangGraph** workflows and agentic architectures.

## Prerequisites
* Python 3.10+
* Git

## Getting Started

### 1. Create and Activate Virtual Environment

#### Linux / WSL (Recommended)
```bash
# Create virtual environment
python3 -m venv .venv

# Activate virtual environment
source .venv/bin/activate
```

#### Windows (PowerShell / CMD)
```powershell
# Create virtual environment
python -m venv .venv

# Activate virtual environment
.venv\Scripts\activate
```

---

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

---

### 3. Run the Project
```bash
# On Linux / WSL
python3 main.py

# On Windows
python main.py
```
