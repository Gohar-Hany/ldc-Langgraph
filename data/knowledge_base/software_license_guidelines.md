# Enterprise Software Licensing, Approval & Access Guidelines

## Overview
This document outlines approved software tiers, license provisioning workflows, and compliance requirements for corporate workstations.

## Approved Pre-Licensed Software Catalog
The following applications are pre-approved and available for immediate self-service install via **Company Portal** (Windows) or **Self Service** (Mac):
- **Collaboration & Communication:** Slack Enterprise Grid, Zoom Meetings, Microsoft Teams.
- **Productivity & Cloud Storage:** Google Workspace (Docs, Sheets, Drive), Microsoft 365 Enterprise, Notion.
- **Development & Tools:** Visual Studio Code, Git, Docker Desktop (with corporate license), Postman.
- **Password Management:** 1Password Enterprise.

## Paid Tier & Specialty Software Request Procedure
Software requiring individual annual licensing (e.g., JetBrains All Products Pack, Figma Enterprise Editor, Tableau, GitHub Copilot) must follow this workflow:

1. **Step 1 - Eligibility Check:** Ensure the tool is listed on the Approved Vendor List. Unapproved vendors must undergo security risk review before purchase.
2. **Step 2 - Manager Approval:** Obtain written or ticket approval from your engineering manager or cost-center owner.
3. **Step 3 - Ticket Submission:** Create a ticket with category **Software Licensing**, specifying:
   - Tool Name and requested license tier.
   - Justification and cost center ID.
4. **Step 4 - Provisioning:** Support Agent validates approval and invites the employee's corporate email to the SaaS vendor organization within 2 business days.

## Prohibited Software & Shadow IT
- Installing peer-to-peer (P2P) file sharing applications (BitTorrent), unapproved remote desktop clients (AnyDesk, TeamViewer), or unauthorized browser extensions with read permissions is strictly prohibited.
- Periodic automated audit scripts scan all workstations for unauthorized executables. Detected infractions are flagged to the Infosec compliance team.
