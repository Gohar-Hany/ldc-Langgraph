# الدليل الشامل والمفصل لمشروع LangGraph Enterprise Support Agent (المرحلة الأولى)

---

## 1. فكرة المشروع والهدف منه ببساطة

المشروع عبارة عن **نظام دعم فني ذكي للشركات (Enterprise IT Support AI Agent)** مبني بتقنيات **LangGraph** و **FastAPI**.

الهدف الأساسي:
عندنا شركة فيها 4 فئات من المستخدمين:
1. **Customer (العميل العادي):** يقدر يسأل أسئلة عامة ويبحث في تذاكره هو فقط.
2. **Support Agent (موظف الدعم):** يقدر يبحث وينشئ ويعدل التذاكر ويفحص الـ APIs الخارجية.
3. **Senior Agent (المشرف/الوكيل الأول):** يقدر يعمل عمليات حساسة زي طلب ترقية الصلاحيات وإعادة تعيين الباسوورد.
4. **Admin (المدير):** معاه كل الصلاحيات + استعلامات وتعديلات قواعد البيانات (Database Queries).

الذكاء الاصطناعي هنا مش مجرد شات بوت عادي بيرد وخلاص، ده **Agent مع مصفوفة صلاحيات (RBAC - Role-Based Access Control)**:
* بيستقبل الرسالة.
* بيفهم نية المستخدم (Intent Classification) باستخدام Structured Output.
* بيفحص هوية ودور المستخدم من الـ JWT Token.
* لو مسموح له بالعملية، بيوجهه للعقدة المخصصة للرد، ولو مش مسموح له بيمنعه فوراً ويديه رسالة 403 Forbidden.

## 2. دليل المكاتب والاعتماديات (كل مكتبة استخدمناها ليه وبتعمل إيه؟)

ملف `requirements.txt` فيه 9 مكاتب أساسية، تعال نفهم كل واحدة فيهم بالتفصيل:

### 1. `langgraph==1.2.11`
* **إيه هي؟** الفريم وورك الأساسية لبناء الـ Agentic Workflows في شكل رسم بياني (Graph).
* **ليه استخدمناها؟** عشان نقسم منطق الشات لعقد (Nodes) ومسارات شرطية (Conditional Edges)، ونقدر ندير حالة المحادثة (State) بدقة، ونتحكم في مين يروح فين بناءً على الصلاحيات.

### 2. `fastapi==0.141.1`
* **إيه هي؟** أقوى وأسرع فريم وورك ويب في بايثون لبناء REST APIs.
* **ليه استخدمناها؟** عشان نكشف منطق الـ LangGraph للعالم الخارجي في شكل Endpoints (`/api/v1/chat`, `/api/v1/auth/token`) يقدر أي تطبيق (موقع، تطبيق موبايل، Slack) يتكلم معاه بسهولة.

### 3. `uvicorn[standard]==0.52.4`
* **إيه هي؟** سيرفر ويب سريع جداً بنظام ASGI (Asynchronous Server Gateway Interface).
* **ليه استخدمناها؟** ده المحرك اللي بيشغل كود الـ FastAPI ويستقبل اتصالات الشبكة من المتصفحات والتطبيقات.

### 4. `langchain-openai==1.6.0`
* **إيه هي؟** الحزمة الرسمية من LangChain للتعامل مع أي سيرفر بيتبع بروتوكول OpenAI القياسي.
* **ليه استخدمناها؟** لأنها الفيشة القياسية اللي بتوصلنا بسيرفرات Aurai Studio وسيرفرات OpenRouter، وبنوجه الـ `base_url` ليها، وبتوفر ميزة `llm.with_structured_output` اللي بتجبر الموديل يرجع JSON منظم بدون أخطاء.

### 5. `pydantic-settings==2.15.0`
* **إيه هي؟** أداة متقدمة من Pydantic لقراءة المتغيرات من ملف `.env`.
* **ليه استخدمناها؟** عشان تطبق مبدأ (Fail-Fast): تفحص المتغيرات الحساسة أول ما السيرفر يقوم، ولو في مفتاح ناقص أو نوعه غلط توقف السيرفر فوراً وتديك رسالة واضحة بدل ما البرنامج يضرب فجأة في الإنتاج.

### 6. `python-dotenv==1.2.3`
* **إيه هي؟** مكتبة مساعدة لتحميل ملفات `.env` في متغيرات البيئة الخاصة بالنظام.
* **ليه استخدمناها؟** بتساعد في بيئات التطوير والاختبار لقراءة المتغيرات من القرص الصلب بسهولة.

### 7. `pyjwt==2.13.0`
* **إيه هي؟** المكتبة القياسية لتوليد وفك تشفير الـ JSON Web Tokens.
* **ليه استخدمناها؟** في معمارية الـ REST API، مينفعش المستخدم يبعت باسوورده مع كل رسالة شات. إحنا بنعمل له توكن مشفر برقم هويته ودوره (`role`) وتاريخ انتهاء الصلاحية، والمكتبة دي بتتحقق من التوقيع الرقمي للتوكن مع كل ريكويست.

### 8. `bcrypt==5.0.0`
* **إيه هي؟** مكتبة متخصصة في تجزئة وتشفير كلمات المرور (Password Hashing).
* **ليه استخدمناها؟** عشان مفيش أي كلمة سر تتخزن كنص عادي، فبيتم تشفيرها بـ Salt قوي يصعب كسره.

### 9. `pytest==9.1.1` و `httpx==0.28.1`
* **إيه هما؟** فريم وورك كتابة الاختبارات الآلية وعميل HTTP متقدم غير متزامن.
* **ليه استخدمناهم؟** عشان نكتب Unit Tests نختبر بيها تصنيف النوايا الـ 8 واختبارات الصلاحيات والـ API بدون ما نحتاج نفتح متصفح أو برنامج خارجي.

## 4. شرح تفصيلي لكل مجلد وملف وكود المشروع

---

### أولاً: مجلد النواة (`app/core/`)

#### 1. ملف `app/core/config.py`:
* **وظيفته:** القلب المسؤول عن كل الإعدادات.
* **الكود جواه بيعمل إيه؟**
  * بيعرف كلاس اسمه `Settings` وارث من `BaseSettings`.
  * بيحدد المتغيرات: نوع الموديل الأساسي (Aurai أو OpenRouter)، عناوين الـ Endpoints، مفاتيح الـ API، إعدادات الـ JWT، ورقم البورت.
  * بيستخدم دالة `get_settings()` المحمية بـ `@lru_cache` عشان تقرأ الملف مرة واحدة بس في الذاكرة وماتستهلكش موارد الجهاز مع كل اتصال.

#### 2. ملف `app/core/logging.py`:
* **وظيفته:** نظام السجلات والمراقبة الموحد (Structured Logging).
* **الكود جواه بيعمل إيه؟**
  * بيعمل Formatter يطبع الوقت واسم العقدة ونوع الرسالة (INFO / WARNING / ERROR).
  * بيساعدنا نعرف الريكويست جه من مين وراح لأنهي نود والوقت المستغرق بالمللي ثانية.

#### 3. ملف `app/core/security.py`:
* **وظيفته:** بوابة التشفير والأمان.
* **الكود جواه بيعمل إيه؟**
  * `hash_password` و `verify_password`: تشفير ومقارنة الباسووردات بـ bcrypt.
  * `create_access_token`: توليد توكن JWT فيه `sub` (اسم/إيميل المستخدم) و `role` (دوره في الشركة) ومدة الصلاحية.
  * `decode_access_token`: فك التوكن والتأكد إنه سليم ومش منتهي ولم يتم التلاعب به.

---

### ثانياً: مجلد العقود ونماذج البيانات (`app/schemas/`)

#### 1. ملف `app/schemas/auth_schema.py`:
* **وظيفته:** تعريف الأدوار والمستخدمين.
* **الكود جواه بيعمل إيه؟**
  * بيعرف الـ Enum `UserRole`:
    * `customer`, `support_agent`, `senior_agent`, `admin`.
  * بيعرف نموذج `UserProfile` و `Token` و `TokenPayload`.

#### 2. ملف `app/schemas/intent_schema.py`:
* **وظيفته:** تعريف النوايا ومصفوفة الصلاحيات (RBAC Matrix).
* **الكود جواه بيعمل إيه؟**
  * بيعرف الـ 8 نوايا:
    1. `greeting`
    2. `knowledge_search`
    3. `my_tickets_search`
    4. `ticket_create_update`
    5. `external_api_search`
    6. `sensitive_operation`
    7. `database_query_operation`
    8. `out_of_scope`
  * مصفوفة `INTENT_REQUIRED_ROLES`: قاموس بيحدد مين الأدوار المسموح لها تشغل كل نية (مثلاً الـ Database محصورة للـ Admin فقط).
  * نموذج `IntentClassificationOutput`: ده شكل الـ JSON اللي الموديل ملزم يرجعه، وفيه: `intent`, `confidence`, `reasoning`, `extracted_entities`.

#### 3. ملف `app/schemas/chat_schema.py`:
* **وظيفته:** شكل مدخلات ومخرجات الـ API.
* **الكود جواه بيعمل إيه؟**
  * `ChatRequest`: بيستقبل `message` و `conversation_id`.
  * `ChatResponse`: بيرجع الرد النهائي، النية المكتشفة، نسبة التأكيد، هل المستخدم مصرح له أم لا، وسجل تتبع العقد `execution_trace`.

---

### ثالثاً: مجلد الخدمات (`app/services/`)

#### ملف `app/services/llm_service.py`:
* **وظيفته:** الاتصال بالموديل الذكي وإدارة المزودين (Aurai و OpenRouter).
* **الكود جواه بيعمل إيه؟**
  * بيفحص المزود المختار من `settings.LLM_PROVIDER`:
    * لو `aurai`: بيعمل اتصال مع سيرفر Aurai Sandbox بموديل `Aurai-3.0`.
    * لو `openrouter`: بيعمل اتصال مع سيرفر OpenRouter.
  * بيفعل ميزة `llm.with_structured_output(IntentClassificationOutput)`.
  * بيحتوي على دالة `classify_intent_fallback` التي تستخدم Regex بحدود الكلمات (`\bhi\b`) لمطابقة النوايا في وضع الاختبارات السريعة والعمل بدون اتصال خارجي.

---

### رابعاً: مجلد الـ LangGraph Agent (`app/agent/`)

#### 1. ملف `app/agent/state.py`:
* **وظيفته:** الذاكرة المشتركة للـ Graph (AgentState).
* **الكود جواه بيعمل إيه؟**
  * بيعرف كائن `TypedDict` بينتقل من عقدة للتانية وفيه: بيانات المستخدم ودوره، نص الرسالة، النية المصنفة، حالة الإذن `is_authorized`، وسجل الخطوات `execution_trace`.

#### 2. ملف `app/agent/prompts/classifier_prompt.py`:
* **وظيفته:** البرومبت الموجه للموديل لشرح الـ 8 نوايا وأمثلة لكل نية والقواعد الإرشادية للتصنيف الدقيق.

#### 3. عقد الـ Graph (`app/agent/nodes/`):
* **`receive_node.py`:** بتستقبل الرسالة، تتحقق من سلامتها، وتضيف أول خطوة في سجل التتبع `execution_trace`.
* **`classify_node.py`:** بتنادي خدمة الـ LLM وتستخرج الـ Structured Output وتخزن النية ونسبة التأكيد في الحالة.
* **`router_node.py`:** بتعمل فحص الـ RBAC؛ بتقارن دور المستخدم الحالي بمصفوفة الصلاحيات، ولو مش مسموح له بتسجل `is_authorized = False` مع رسالة سبب المنع.
* **`response_nodes.py`:** مجموعة من العقد المتخصصة:
  * `handle_greeting`: توليد رد الترحيب.
  * `handle_knowledge_search`: الرد بمعلومات الدعم الفني وإعدادات الـ VPN.
  * `handle_my_tickets_search`: استعراض تذاكر العميل.
  * `handle_ticket_create_update`: إجراءات إنشاء وتعديل التذاكر.
  * `handle_external_api_search`: فحص حالة الـ APIs وسيرفرات الخدمات.
  * `handle_sensitive_operation`: معالجة العمليات الحساسة وتجهيزها للموافقة البشرية.
  * `handle_database_query`: تنفيذ وفحص استعلامات قواعد البيانات للـ Admin.
  * `handle_unauthorized`: الرد برسالة 403 Forbidden وتوضيح الصلاحية الناقصة.
  * `handle_fallback`: التعامل مع الأسئلة الخارجة عن نطاق الـ IT.

#### 4. ملف `app/agent/edges/routing_rules.py`:
* **وظيفته:** شرط التوجيه الذكي (Conditional Edge).
* **الكود جواه بيعمل إيه؟**
  * دالة `route_after_rbac_check`: بتفحص:
    * لو `is_authorized == False` ⬅️ وجه الفلو لعقدة `handle_unauthorized`.
    * لو `is_authorized == True` ⬅️ وجه الفلو للعقدة المتخصصة بالنية المصنفة.

#### 5. ملف `app/agent/graph.py`:
* **وظيفته:** تجميع الجراف بالكامل.
* **الكود جواه بيعمل إيه؟**
  * بينشئ `builder = StateGraph(AgentState)`.
  * بيسجل كل الـ Nodes.
  * بيوصل الحواف المتسلسلة من `START` لـ `receive_message` لـ `classify_intent` لـ `router_node`.
  * بيوصل الحواف الشرطية من `router_node` لكل عقد الردود.
  * بيوصل كل عقد الردود بنقطة النهاية `END`.
  * بيعمل `builder.compile()` لتوليد الكائن الجاهز للتشغيل `enterprise_agent_graph`.

### خامساً: مجلد الـ API والـ Web Server (`app/api/` و `app/main.py`)

#### 1. ملف `app/api/dependencies.py`:
* **وظيفته:** حارس البوابة (Security Dependency).
* **الكود جواه بيعمل إيه؟**
  * دالة `get_current_user`: بتستخرج الـ Bearer Token من الـ Request Header، وتفكه وترجع كائن المستخدم ودوره. لو مفيش توكن بتعتبره عميل زائر (Guest Customer).
  * دالة `require_role`: دالة حماية إضافية للـ Endpoints تتأكد إن الـ Endpoint محصورة لأدوار معينة.

#### 2. ملفات الـ Middlewares (`app/api/middlewares/`):
* `auth_middleware.py`: بيقيس زمن معالجة كل ريكويست بالمللي ثانية ويضيف هيدر `X-Process-Time-Ms`.
* `error_handler.py`: بيمسك أي خطأ غير متوقع ويوحد شكل الـ JSON المرتجع عشان السيرفر ميرجعش كود HTML غير مفهوم للعميل.

#### 3. ملفات الـ Endpoints (`app/api/v1/endpoints/`):
* `auth.py`: فيه مسار `POST /api/v1/auth/token` لتوليد توكنات فورية لتجربة أي دور، ومسار `GET /api/v1/auth/me`.
* `chat.py`: فيه مسار `POST /api/v1/chat` اللي بياخد رسالة المستخدم وينفذ جراف الـ LangGraph ويرجع النتيجة وتفاصيل العقد المنفذة.

#### 4. ملف `app/main.py`:
* **وظيفته:** نقطة الانطلاق الرئيسية للتطبيق.
* **الكود جواه بيعمل إيه؟**
  * بينشئ تطبيق الـ FastAPI.
  * بيفعل الـ CORS والـ Middlewares ويوصل مسارات `/api/v1`.
  * بيوفر مسار الفحص السريع `/health` وواجهة Swagger التفاعلية على `/docs`.

### سادساً: مجلد الاختبارات الشاملة (`tests/`)

1. **`conftest.py`:** بيوفر الـ TestClient وتوكنات جاهزة لكل دور من الأدوار الـ 4.
2. **`test_intent_classifier.py`:** بيفحص دقة تصنيف الـ 8 نوايا المختلفة والتأكد من عدم حدوث تداخل بين الكلمات.
3. **`test_rbac_router.py`:** بيفحص مصفوفة الأمان (رفض العميل للـ Database والـ Sensitive، وسماح موظف الدعم بالتذاكر، وسماح الـ Admin بكل شيء).
4. **`test_auth.py`:** بيفحص تجزئة الباسووردات بـ bcrypt وتوليد وفك الـ JWT.
5. **`test_api_chat.py`:** بيفحص استجابة الـ Endpoints والـ Status Codes.
6. **`runner.py`:** سكربت بايثون مستقل لتشغيل كل هذه الاختبارات وطباعة تقرير كامل في التيرمينال.
